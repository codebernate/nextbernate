# Knowledge workflow

The vault root is `knowledge/`. Use the bundled skill at `.agents/skills/obsidian-second-brain/SKILL.md` from repository root.

1. Read the index and relevant notes before changing knowledge.
2. Search existing notes before creating one.
3. Update existing notes when accepted decisions or code change their facts.
4. Preserve frontmatter, headings, wikilinks, task syntax, and provenance.
5. Verify links and claims against code or their source.

Small edits do not need a session log. Naming and decomposition are contextual guidelines, not automated gates. See [[conventions/code-organization]] and [[conventions/development-workflow]].
