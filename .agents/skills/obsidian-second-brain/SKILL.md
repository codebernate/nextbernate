# Obsidian Second Brain

## Use This Skill

Use this skill for vault work that should stay in Markdown and compound over time:

- Update existing notes instead of creating duplicates.
- Preserve headings, frontmatter, wikilinks, and task syntax.
- Keep changes small, traceable, and easy to merge back into the vault.
- Route work into the right note type when it already exists, especially daily, project, person, review, and capture notes.

## Workflow

1. Inspect the vault context first.
2. Prefer updating the most relevant existing note.
3. Keep markdown stable and avoid unnecessary rewrites.
4. Preserve provenance when summarizing or ingesting source material.
5. Verify links, task formatting, and frontmatter after edits.

## Good Fits

- Capture a new idea into the vault.
- Summarize a conversation into a durable note.
- Update a project note, daily note, or person note.
- Maintain links, tags, and task lists across notes.
- Prepare or refine Obsidian-second-brain command content.

## Notes

If the task needs vault-specific rules, consult the project's Obsidian conventions before making broad edits. Keep the skill focused on repeatable vault operations, not general project management.
